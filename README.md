# Botania Energistics

Botania mana for [AE2 Unofficial Deconstructed](https://github.com/romanfedyniak/AE2UD), for Minecraft 1.12.2.

Mana joins AE2UD as a kind of content an ME network holds, the way items and fluids do, so the terminals,
buses, storage buses and interfaces AE2UD already has carry it. What this mod adds of its own is what has no
counterpart there: mana storage cells and their components, portable mana cells that work as a mana tablet,
the Fluix Mana Pool, a P2P tunnel for mana bursts and drawing mana from the network through a wireless
terminal.

It is written from scratch. Several of its ideas come from two earlier addons, credited in
[CHANGES.md](CHANGES.md) where each one lands: [Applied Botanics](https://github.com/ramidzkh/Applied-Botanics)
by ramidzkh, for modern Minecraft, and [Botania Applie](https://github.com/NNYYOONNIIOO/Botania_Applie) by
NNYYOONNIIOO, for 1.12.2 on AE2 UEL.

Built against Botania r1.10-364.

## Compatibility

- This mod runs only with AE2 Unofficial Deconstructed, not with standard AE2 or AE2 Unofficial Extended Life.
- Back up the world before installing or updating.
